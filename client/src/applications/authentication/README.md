## Session management

### What we have deliberately NOT done

At this point I would not add:

revoke-session buttons
revoke-all-other-sessions
confirmation dialogs
optimistic updates
session deletion from local state
polling
WebSockets
a separate security API service
a new applications/identity
a new backend security domain
token manipulation in SecurityPage
raw User-Agent display
automatic session refresh logic in the feature

Those belong to later stages or existing platform infrastructure.
