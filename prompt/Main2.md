- I am working on a project in VS Code. What i do is i go to the various LLM websites:
    - For primary(main) development i have been using ChatGPT and DeepSeek.
    - For secondary(purposeful) development i occasionally use Grok, Claude and or Copilot.
- I then open a project or start a chat with the LLM through giving it a prompt, then i critic and extract what i need from the response and bring it back to the project in VS Code. We are building the application together but the LLM responsible is not actually connected to it. If i were to change something locally, the LLM will not know such an event took place not unless i inform it about it. This happens because they don't have a preview of the projects context leading them to sometimes end up duplicating and or creating new concepts or stray away from the main objective. When the conversation starts to grow longer they start to forget.
- Not being connected, not knowing what is, all this limitations pile up leading to a stressful and or deranged development experience. For one, sometimes the LLM would drift away from the main objective, sometimes recommend that we tackle a milestone that was already dealt with and built and sometimes just forget.
- You could say that i use VS Code's copilot or similar options but these to come with their own tier limitation.
- Each time i have decided to start a new chart i have made it as a routine to ask the LLM to draft the initial prompt for the next chat.
- The thought is that we create a way for the LLM models to be connected or integrated to the project and gain access to it's files.
